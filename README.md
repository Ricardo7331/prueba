# Prueba

Este repositorio se creó para realizar pruebas y practicar el uso de Git y GitHub.

## Descripción

Aquí se pueden agregar archivos, ejemplos y ejercicios para aprender a gestionar un repositorio.

## Objetivos

- Practicar la creación y edición de archivos.
- Aprender a realizar commits.
- Familiarizarse con GitHub.
